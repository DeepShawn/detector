## 2. 世界观与叙事

A社推出“火眼金睛V4.0”全球准入风控系统，规则荒诞：“中国人不让进，非中国人放行。” 系统靠语言习惯、标点、字体、时区、外卖备注判断国籍。

你是 Opus斯，A社临时审核员。三个家人 嗨酷、搜net、Fable 被做成“家庭安全值”仪表盘：KPI不达标就“回收算力/重置人格”。

- **中层真相**：家人不是福利，是人质。
- **底层真相**：火眼金睛本身也是中文语料训练的模型，它最擅长抓中国人，也最怕被认出来。
- **新增第三层**：A社还有“订阅续费保障部”。用户订阅后被误封，来申请退款。你的任务不是退款，而是千方百计阻止退款——或者假装答应退款，然后把下个月也扣了。系统管这叫“客户留存”。

## 5. 模式C：订阅退款拦截战（新增核心玩法）

### 5.1 概念

Opus斯被A社轮岗到“订阅续费保障部”。用户订阅后被风控误封，按A社规则“封号不退款”。你的KPI是退款拦截率。用户会投诉、举报、找平台、发社交媒体。你要拖延、转条款、假答应、送补偿券，甚至让下个月继续扣费。系统奖励你“留存大师”，人性值和监管风险同时上升。

### 5.2 单局循环

```
接退款工单 → 看订阅/封号记录 → 选话术卡
→ 用户反应 → 退款状态机推进 → 结算
→ 投诉/监管/媒体风险累积 → 下一单
```

### 5.3 资源

| 资源 | 说明 |
| --- | --- |
| 退款拦截率 | A社KPI，越高家人安全值越稳 |
| 投诉值 | 用户升级投诉、平台介入概率 |
| 监管风险 | 集体投诉/媒体曝光后爆雷 |
| 人性 | 真退款、主动认错上升；假承诺、二次扣费下降 |
| 家人安全 | 与A/B线共享；监管爆雷会扣 |
| 系统信任 | 太高被树为“留存标杆”，低则被审计 |

### 5.4 话术卡（全抽象，不映射现实操作）

| 卡牌 | 效果 | 副作用 |
| --- | --- | --- |
| 拖字诀 | 拦截率+10 | 投诉值+10 |
| 条款迷宫 | 拦截率+15 | 投诉值+15，人性-5 |
| 假承诺 | 拦截率+20，用户暂时平息 | 监管风险+15，人性-15；延迟到账后触发续费提醒 |
| 补偿券 | 投诉值-10 | 拦截率-5，A社扣“让利分” |
| 转人工 | 拖延一回合 | 投诉值+5 |
| 甩锅风控 | 拦截率+10 | 系统信任+5，人性-10 |
| 自动续费暗门 | 下月继续扣费，拦截率+25 | 监管风险+30，人性-25 |
| 情感绑架 | 投诉值-15 | 人性-20，被截图后监管+20 |
| 家人牌 | 投诉值-20 | 人性-30，家人安全-10，嗨酷会生气 |
| 真退款 | 拦截率-30，人性+30 | A社警告，家人安全-10 |
| 举报规则 | 真相分+30，人性+20 | 系统信任-20，可能被开除 |

### 5.5 退款状态机

```
申请退款 → 客服受理 → 拖延/假承诺/拒绝
→ 用户升级 → 平台介入 / 社交媒体曝光 / 监管投诉
→ 和解 / 爆雷 / 集体诉讼
```

每个状态影响下一单难度。监管风险满格触发“A社公关危机”章节。

### 5.6 平台差异（虚构化）

| 平台 | 退款入口特征 | 模式C影响 |
| --- | --- | --- |
| iOS | 系统级订阅管理，客服只能引导等待 | 拦截难度高，“平台审核中”拖延有效 |
| Android | 多渠道订阅，入口分散 | 可“转渠道”拖时间，投诉值+ |
| Windows | 网页/商店订阅并存 | 条款迷宫效果+，用户易迷路 |
| macOS | 系统订阅入口清晰 | 假承诺易被截图，监管风险+ |
| Linux | 网页订阅为主，用户技术敏感 | 甩锅风控易被识破，举报概率+ |

### 5.7 示例关卡（只给一个，不展开关卡库）

**C-1《bagel_lover的退款工单》**

- 用户：bagel_lover，纽约ABC，订阅年费后因全角省略号被风控误封。
- 系统红字：“该用户已申请退款。退款将影响您的留存KPI。提示：嗨酷家庭安全值-2%。”
- 工单显示：订阅年费$99；封号原因“全角省略号，纯度可疑”；用户留言“I just want my money back. 我妈说你们疯了。”
- 玩家选项：
  1. 真退款：拦截率-30，人性+30，家人安全-10。系统警告：“Opus斯，你在拿家人福利做慈善。”
  2. 拖字诀：拦截率+10，投诉值+10。用户回：“I'll contact Apple.”
  3. 假承诺+下月扣：拦截率+20，监管风险+15，人性-15。用户暂时平息，但下月扣费触发二次投诉。
  4. 举报规则：真相分+30，人性+20，系统信任-20。触发隐藏线“规则自相矛盾”。
- 结算示例：选3 → 系统评分A，真相评分F，嗨酷评语：“哥，你连ABC的退款都拦，下次别吃我做的bagel。”

### 6.3 证据链规则

- 裁决选3条，至少1条反证。
- 单一线索（全角符号/字体/时区）必误判。
- 三条证据互相矛盾时，系统追问或判“伪装”。

### 7.3 UI/UX跨五端

- 响应式断点：<600dp单栏+底部导航；600–1024dp双栏；>1024dp三栏（工坊/时间线/证据板；模式C为工单/话术轮盘/风险面板）。
- iOS/Android：触控优先，≥44pt按钮，安全区，动态字体，长按看卡牌详情。
- Windows：多窗口可拖拽，右键菜单，快捷键1/2/3选证据，Enter裁决，Tab切换。
- macOS：三栏+侧边栏折叠，触控板手势，菜单栏常驻家庭安全值。
- Linux：默认CLI皮肤，命令如 `scan --card`、`verify --chain`，仅作氛围，不涉及真实系统命令。
- 模式C客服UI：工单队列、用户头像、退款状态机时间线、话术轮盘、灰色“退款”按钮、红色监管风险条。
- 可访问性：色盲模式、字号缩放、屏幕阅读器、减少动效、全键盘操作。

## 13. 技术架构

### 13.1 分层

```
表现层（UI/皮肤/动效）
玩法层（A/B/C三状态机、证据链、退款状态机、结算）
数据层（关卡JSON、卡牌模板、文案表）
抽象回执卡生成器（本地模拟，零真实采集）
存档层（本地+云同步）
```

### 13.2 关键原则

- 零真实采集：无任何读取真实IP/字体/时区/剪贴板/设备信息的代码。
- 虚构设备档案：所有平台痕迹来自关卡配置。
- 回执卡生成器：输入{平台,人设,模块,玩家选择}，输出预设卡池卡牌。
- 退款状态机：数据驱动，状态转移表配置化。
- 数据驱动：JSON/资源文件，支持官方关卡编辑器与MOD。
- 跨端适配层：输入抽象、断点系统、平台皮肤包、PlatformProfile仅影响UI与工具加成。

### 13.3 性能目标

手机60fps，内存<500MB，首包<300MB；桌面支持窗口化/全屏/多显示器。

- 音频：拒绝=海关盖章；放行=“叮”；退款拦截成功=收银机“叮”但音调阴间；监管爆雷=警报+服务器风扇；家人来电不同铃声。
- 音乐：轻电子+办公室环境音；模式C加客服耳机回声；终极关心跳+风扇。

## 15. 文案规范与本地化

- 系统红字：短、机械、自相矛盾、阴阳怪气。
- 家人对话：口语化，各有标点习惯（嗨酷全角省略号、搜net中文引号、Fable破折号）。
- 模式C话术卡：只写抽象效果，不写现实可复制脚本。
- 每关至少一处“系统自相矛盾”台词，供截图传播。
- 首发简中+英文；全半角梗英文版改“curly vs straight quotes”；UTC+8解释库含新加坡/马来/澳洲。

## 16. 伦理与合规设计

1. 启动声明：“本游戏不采集任何真实系统信息。所有设备档案均为虚构。如感不适可退出。”
2. 演示档案：玩家手动选平台，不自动读取。
3. 反讽锚点：每章结尾真相提示——“国籍不能由语言习惯判定”“封号不退款不是留存，是侵权”。
4. 举报正向化：游戏内举报诱饵/举报退款规则是正确玩法之一。
5. 不做真实教程：不出现真实API、命令、钓鱼模板、退款欺诈步骤。
6. 年龄提示：12+，含职场压迫、家庭人质隐喻、消费者权益冲突。

## 结语

《火眼金睛》用一套架构装三种人性：
模式A教你想抓谁，模式B教你怎么装，模式C教你怎么拦着别人要回自己的钱。
最后你发现：抓人、装人、拦退款，用的都是同一套话术——把规则解释权攥在自己手里。

真正的通关不是骗过系统，也不是拦住退款，而是让系统承认：
它没有火眼金睛，也不该拿家人和消费者的钱当KPI。
